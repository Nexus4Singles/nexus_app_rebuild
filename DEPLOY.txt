# DEPLOY COMMANDS FOR DAILY LIMIT RESET SYSTEM

Run these commands in order:

## 1. Deploy Cloud Function
cd /Users/aybaj/Documents/nexus_app_v2
firebase deploy --only functions:resetDailyLimits

## 2. Verify deployment
firebase functions:log --only resetDailyLimits

## 3. Check function is scheduled
# Go to Google Cloud Console → Cloud Pub/Sub → resetDailyLimits
# Should show: "Subscription created" and "Runs every day at 00:00 UTC"

## Summary of what was implemented:

- Daily limit reset CloudFunction (runs daily at 00:00 UTC)
- Atomic deletion of trading.dailyLimitFirstHit and dating.shownProfileIds
- FCM notifications sent after reset succeeds
- Audit trail logged to Firestore
- Client-side lazy reset as failsafe backup
- FCM token storage updated to save to fcmTokens array

## What happens after deployment:

1. Every day at midnight UTC, CloudFunction automatically runs
2. Finds all free users whose 24h limit has expired
3. Atomically clears their daily limit fields
4. Sends notification: "✨ New Profiles Available!"
5. If CloudFunction fails, lazy reset catches it when user searches
