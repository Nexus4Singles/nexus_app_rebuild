   ├── verification/data ...... Verification state
   ├── settings/data .......... Settings
   ├── assessments/ ........... Assessment records
   ├── journeys/ .............. Journey progress
   ├── stories/ ............... Stories
   └── polls/ ................. Polls

   Time: ~15 minutes

   Time: 4-6 hours

================================================================================
                           KEY DECISIONS
================================================================================

❌ NOT Removing (Even Though Similar):
   maritalStatus:
   - Used 6+ times in compatibility code
   - Not a duplicate - it's a required field
   
   dating.reviewPack.*:
   - Different from dating.audioPrompts[]
   - reviewPack is immutable snapshot for verification
   - audioPrompts[] are live/changeable user data
   - Verification workflow depends on immutability

✅ Removing (Unused Duplicates):
   All 7 fields listed above have:
   - Primary field exists elsewhere
   - Not referenced in any Dart code
   - Safe to remove with zero app impact
